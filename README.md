# Weddings by Edward website (React)

Built with React + Vite. Vercel builds it automatically.

- **Change text, contact details or portfolio photos:** edit `src/content.js`.
- **Add or replace photos:** upload them to `public/images` (same file name replaces the old one).
- **Change the look:** `src/index.css`.

Vercel settings: Framework **Vite**, Build command `npm run build`, Output directory `dist` (Vercel detects these automatically).
